# udslib.com

Static site for UDSLib (GitHub Pages). Hand-written HTML, one `style.css`, one `site.js`, no build step.

- Check links and page structure: `python3 scripts/check_site.py`
- Preview: `python3 -m http.server 8099`
- `mcp-worker/` is the Cloudflare Worker behind the UDS toolbox MCP server.
- Design and plan: `docs/superpowers/`
