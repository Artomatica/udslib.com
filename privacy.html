Privacy policy

Last updated 4 October 2026.

This policy covers the website udslib.com and the uds-toolbox MCP server at mcp.udslib.com, both run by Andrii Shylenko e.v. (Hungary). Contact: andrii@shylenko.com.

uds-toolbox MCP server

  • The server needs no account and asks for no personal data.
  • Tool inputs (hex bytes, CAN frames, DTCs, topics, target names) are processed in memory to build the reply and are not stored or logged by us.
  • We keep no conversation content. When you use the server through ChatGPT, Claude or another client, that client's own privacy terms apply to your conversation.
  • The server runs on Cloudflare Workers. Cloudflare processes connection data such as IP addresses to deliver and protect the service, under the Cloudflare privacy policy. We see only aggregate request counts.
  • Do not paste secrets such as production security keys into tool inputs. The tools do not need them.

Website

  • udslib.com is hosted on GitHub Pages, which logs visitor IP addresses for security (GitHub privacy statement).
  • We use Google Analytics 4 to count page views and clicks (for example on the email link or the MCP copy buttons). Google sets cookies for this. You can block them with your browser settings or the Google Analytics opt-out add-on.
  • If you email us, we keep the email to answer you and, for license orders, as long as accounting law requires.

Your rights

Under the GDPR you can ask what we hold about you, and ask us to correct or delete it. Write to andrii@shylenko.com. You can also complain to the Hungarian data protection authority (NAIH).

Changes

We will update the date above when this policy changes.
