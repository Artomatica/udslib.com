Portable ISO 14229 UDS stack for embedded ECUs

UDSLib is a C99 implementation of ISO 14229-1 (UDS) with ISO-TP over CAN and CAN-FD. It allocates no heap, runs on Zephyr, FreeRTOS, bare metal and Linux, and implements all 27 application services. Source is available; commercial use needs a license.

What you get

Zero malloc, C99

All memory is owned by the application. No heap use anywhere in the stack.

ISO-TP built in

ISO 15765-2 over classic CAN and CAN-FD, with flow control, STmin, block size and N_Cr / N_Bs timeouts. On Zephyr or Linux you can use the OS ISO-TP stack instead. See the FAQ.

Runs where you need it

Zephyr, FreeRTOS, bare metal super-loop, POSIX host simulator. STM32F103 and STM32H5 examples.

MISRA-aligned

MISRA-C:2012 is checked in CI with no mandatory-rule violations. Required and advisory deviations are listed in docs/MISRA.md.

Client and server

An ECU-side server stack, plus a small client (tester) API for host tools and test rigs.

Tooling

Wireshark dissector, Python bindings (pyudslib), a host simulator, and an HTML session report for captured traces.

UDSLib and iso14229

driftregion/iso14229 is the other open-source C UDS library people ask about. It is a good project. Here is where each one is stronger.
