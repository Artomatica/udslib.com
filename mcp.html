UDS toolbox MCP server

A free MCP server with general UDS, ISO-TP and DTC tools for AI coding assistants. It works offline on the data you send it, needs no hardware or account, and does not store anything. It is not tied to UDSLib: use it with any UDS stack.

Endpoint

https://mcp.udslib.com/mcp

Streamable HTTP, stateless. Tool inputs are processed in memory and are not stored or logged.

Tools

ToolWhat it does
analyze_traceAnalyze a whole CAN trace (Vector BLF/ASC, PEAK TRC, ASAM MF4, pcap/pcapng, candump, CSV; text pasted or any of them uploaded): reassembles ISO-TP, pairs requests with responses, measures P2/P2*, rebuilds flash downloads with CRC32, and names the root cause with the frames that show it. In ChatGPT the result opens as the trace viewer.
decode_udsDecode a UDS message: service, sub-function, DIDs, routine IDs, DTCs, and the name and typical cause of a negative response code.
build_uds_requestBuild the bytes for a UDS request such as ReadDataByIdentifier, SecurityAccess, RoutineControl or RequestDownload, with an annotated breakdown.
decode_isotpReassemble ISO-TP from a list of CAN frames or a candump log. Reports frame types, flow control values, sequence errors and N_Bs / N_Cr timing problems.
decode_dtcTurn a 3-byte DTC into an SAE J2012 code (P0123-45 form) and explain the status byte bits.
uds_referenceShort reference notes with ISO 14229-1 clause numbers: services, NRCs, identifiers, P2 / P2* / S3 timing, sessions, and a typical reprogramming sequence.
udslib_integrationSuggests the UDSLib files, config settings, init skeleton and closest example for your target, RTOS and features, plus the license terms.

Add it to your client

Claude Code

claude mcp add --transport http uds-toolbox https://mcp.udslib.com/mcp

Claude Desktop and Cursor

Add this to the MCP servers config of the client.

{
  "mcpServers": {
    "uds-toolbox": {
      "url": "https://mcp.udslib.com/mcp"
    }
  }
}

ChatGPT

Open Settings, then Connectors, add a custom connector, and paste the endpoint URL above.
